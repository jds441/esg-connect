# esg-connect

The sign-in and consent page for the ESG Suite's Claude connector (Supabase Auth OAuth 2.1 authorization path `/oauth/consent`).
A static page only: it holds the Supabase project's publishable key, which is public by design, and no secret.
Source of truth: `supabase/functions/esg-mcp-test/consent_page.ts` in the ESG Dashboard repository.
